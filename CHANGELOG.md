# Changelog

## 0.1.0

- First release: connect the site to a Hibira Live Chat workspace in one click (Sign in with Hibira) or with the workspace ID, and show the chat on every page.
- Options: show or hide the chat, the round button, hide it from signed-in staff, colour, site or browser language.
- Verified visitors: with an identity secret, signed-in users get a signed user ID (and, unless turned off, name and email).
- `[hibira_live_chat]` shortcode and links to `#hibira-live-chat` open the chat.
